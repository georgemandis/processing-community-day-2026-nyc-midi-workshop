# launchpad-automata (p5.js)

What it does, controls and assumptions: `../../launchpad-automata.md`.

Serve the repo over http or open it on the live site, click once to connect MIDI. Allow SysEx. The page loads `midi-helpers.js` from the repo with a hosted
fallback, so it also works from a downloaded folder or in the p5 web editor (`../../../starters/p5/README.md`).
