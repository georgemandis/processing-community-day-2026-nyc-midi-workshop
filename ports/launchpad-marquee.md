# Launchpad Marquee

Port of `../launchpad-marquee/`. Scrolling text on the Launchpad, like a `<marquee>` tag from 2002. The text
is rasterised with a 5×7 font into a strip of columns; every tick the sketch composes an 8×8 frame and paints
the pads. The window previews the same 9×9 grid. `font5x7.js` became the `FONT` table at the top of each
sketch, generated by a script (Adafruit GFX `glcdfont.c`, BSD licence).

| | Open |
|---|---|
| Java | `java/LaunchpadMarquee/LaunchpadMarquee.pde` |
| Python Mode | `python/launchpad_marquee/launchpad_marquee.pyde` |

Needs the Launchpad and PipSqueak helper tabs. The PipSqueak is optional.

## Controls

| Where | Control | Does |
|---|---|---|
| Launchpad | top row 1–4 | direction: up, down, left, right |
| | right column, top seven | speed, 1–7 pixels per tick |
| | bottom-right (Stop Solo Mute) | play / pause (green / orange) |
| | logo | restart |
| PipSqueak | left / right | slower / faster |
| | up / down | hue |
| | button | play / pause |
| keyboard | type, Enter | replace the text (Backspace edits) |
| | arrows | direction |
| | `[` `]`, `-` `=` | speed, tick delay (20–500 ms) |
| | `b` | behaviour: scroll, slide (run in and stop), alternate (bounce) |
| | `m` `c` `t` | colour mode (solid, rainbow, per letter, cycle), next hue, trail |
| | space | play / pause |
| | `s` | stock mode: one SysEx (`pad.text()`) and the Launchpad's own firmware scrolls the text; `s` again returns |

Single-key controls work until you start typing a word; Enter applies the word and returns to controls.

## Changes from the p5 original
- No control panel and no HTML export. Blink is gone; trail stays.
- Up / down lay the glyphs out vertically, one per line, as in the original.
- Pads are painted at half brightness every frame; the helper sends only what changed.

## Assumptions
- The stick nudges speed and hue every tenth frame while pushed past half deflection: a push is a rate.
- Python: state in the `S` dict; polling refreshes the helpers; `stop()` closes both devices.
